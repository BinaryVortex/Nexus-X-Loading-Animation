# Nexus X Loading Animation

Nexus X Loading Animation built using pure HTML and CSS.

![Nexus X Loading Animation](https://raw.githubusercontent.com/BinaryVortex/Nexus-X-Loading-Animation/main/Screenshot%202024-08-25%20205232.png)

## Overview

A small, lightweight loading animation inspired by the "Nexus X" style. No JavaScript required — just HTML and CSS. Perfect for landing pages, portfolio sites, or any place you want a clean, modern loader.

## Features

- Pure HTML & CSS (no JavaScript)
- Lightweight and easy to customize
- Easily change colors, size, and animation speed via CSS variables

## Demo / Preview

Open `index.html` in your browser to see the animation in action. The screenshot above shows a still preview of the loader.

## Usage

1. Clone or download this repository:

   git clone https://github.com/BinaryVortex/Nexus-X-Loading-Animation.git

2. Open `index.html` in your browser.

3. To embed the loader in your project, copy the HTML markup from `index.html` and the CSS from `style.css` into your project.

Example (basic structure):

```html
<!-- index.html -->
<link rel="stylesheet" href="style.css">
<div class="nexus-x-loader">
  <!-- loader structure from index.html -->
</div>
```

Then customize the CSS variables in `style.css` to change colors, size, or speed.

## Customization

Open `style.css` and look for the top-level CSS variables (or root rules) to tweak:

- Colors: change the accent and background colors
- Size: increase/decrease dimensions
- Speed: adjust the animation-duration settings
